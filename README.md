# 📰 Fake News Detection using Machine Learning

A Machine Learning and NLP-based web application that detects whether a given news article is **Fake** or **Real**. The project uses text preprocessing, TF-IDF feature extraction, and a trained machine learning model to classify news content.

## 🚀 Live Demo

The project can be deployed using **Streamlit**.

## 📌 Project Overview

Fake news can spread rapidly through social media and online platforms. This project aims to automatically identify potentially fake news using Natural Language Processing (NLP) and Machine Learning techniques.

The application allows users to enter a news headline or article and predicts whether the news is:

* ✅ **Real News**
* ❌ **Fake News**

The application also provides an explanation of the prediction using **LIME (Local Interpretable Model-Agnostic Explanations)**.

## ⚙️ Methodology

The project follows these major steps:

### 1. Data Collection

A labelled news dataset containing real and fake news articles is used for training and evaluation.

### 2. Text Preprocessing

The raw news text is cleaned before being given to the machine learning model.

The preprocessing includes:

* Converting text to lowercase
* Removing punctuation
* Removing URLs and unnecessary characters
* Removing stopwords
* Tokenization
* Removing unnecessary whitespace

### 3. Feature Extraction

The cleaned text is converted into numerical features using **TF-IDF (Term Frequency-Inverse Document Frequency)**.

TF-IDF helps the model identify words that are important for distinguishing between fake and real news.

### 4. Model Training

Machine learning algorithms are trained using the extracted TF-IDF features.

The trained model is then saved and used by the Streamlit application for prediction.

### 5. Prediction

When the user enters news text, the application:

```text
Input News
     ↓
Text Cleaning
     ↓
TF-IDF Transformation
     ↓
Trained ML Model
     ↓
Fake / Real Prediction
```

### 6. Explainable AI

**LIME** is used to explain individual predictions by showing which words contributed to the model's decision.

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/Tusharsingh011/Dynamics_Networks_Fake_News_detection_project.git
```

Move into the project directory:

```bash
cd Fake_News_detection_project
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate the virtual environment on Windows:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Run the Streamlit application:

```bash
streamlit run app/app.py
```

The application will open in your browser.
